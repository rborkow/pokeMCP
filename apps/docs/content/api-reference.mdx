# API retirement

PokeMCP no longer offers a supported public REST or MCP API.

The following endpoints return `410 Gone`:

- `https://api.pokemcp.com/mcp`
- `https://api.pokemcp.com/sse`
- `https://api.pokemcp.com/api/tools`

This retirement was immediate; there is no compatibility window. Existing shared-team links remain readable.

Analysis is now called through private Cloudflare service bindings by **[PokeMCP Prep](https://www.pokemcp.com)**.
