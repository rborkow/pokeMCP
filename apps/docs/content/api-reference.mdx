# REST API

For programmatic access without MCP, use the stateless REST API.

## Endpoint

```
POST https://api.pokemcp.com/api/tools
```

## Request Format

```json
{
  "tool": "tool_name",
  "args": {
    "param1": "value1",
    "param2": "value2"
  }
}
```

An optional `X-Session-Id` header groups related calls together for analytics; if omitted, a
random session id is generated per request.

## Response Format

```json
{
  "jsonrpc": "2.0",
  "id": null,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "Tool response text..."
      }
    ]
  }
}
```

## Examples

### Get Usage Statistics

```bash
curl -X POST https://api.pokemcp.com/api/tools \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "get_usage_stats",
    "args": {
      "type": "meta_threats",
      "format": "gen9ou",
      "limit": 5
    }
  }'
```

### Look Up a Pokémon

```bash
curl -X POST https://api.pokemcp.com/api/tools \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "lookup_pokemon",
    "args": {
      "pokemon": "Garchomp"
    }
  }'
```

### Validate a Team

```bash
curl -X POST https://api.pokemcp.com/api/tools \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "validate_team",
    "args": {
      "team": [
        {"pokemon": "Garchomp", "moves": ["Earthquake", "Dragon Claw"]},
        {"pokemon": "Landorus-Therian", "moves": ["U-turn", "Earthquake"]}
      ],
      "format": "gen9ou"
    }
  }'
```

### Get Popular Sets

```bash
curl -X POST https://api.pokemcp.com/api/tools \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "get_usage_stats",
    "args": {
      "type": "popular_sets",
      "pokemon": "Kingambit",
      "format": "gen9ou"
    }
  }'
```

### Metagame Trends

```bash
curl -X POST https://api.pokemcp.com/api/tools \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "get_meta_trends",
    "args": {
      "type": "shifts",
      "format": "champions-regmb",
      "window": 3
    }
  }'
```

### Query Strategy (RAG)

```bash
curl -X POST https://api.pokemcp.com/api/tools \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "query_strategy",
    "args": {
      "query": "How do I counter Kingambit?",
      "format": "gen9ou"
    }
  }'
```

## Available Tools

All 7 tools are available via the REST API, with the same names and arguments as the [MCP tools
reference](/tools):

| Tool | Required Args | Optional Args |
|------|---------------|----------------|
| `lookup_pokemon` | `pokemon` | `generation` |
| `validate_moveset` | `pokemon`, `moves` | `generation` |
| `validate_team` | `team` | `format` |
| `suggest_team_coverage` | `current_team` | `format` |
| `get_usage_stats` | `type` | `pokemon`, `format`, `limit` |
| `get_meta_trends` | `type` | `pokemon`, `format`, `from`, `to`, `window`, `limit` |
| `query_strategy` | `query` | `pokemon`, `format`, `sectionType`, `limit` |

## Other Endpoints

`/api/tools` is the stateless REST entry point, but the same tool registry also powers two MCP
transports if you're connecting an MCP client directly instead of calling REST:

| Path | Method | Purpose |
|------|--------|---------|
| `/mcp` | POST | MCP protocol over streamable HTTP (used by the Claude.ai Custom Connector) |
| `/sse` | GET | MCP protocol over SSE transport |
| `/api/tools` | POST | Stateless REST tool invocation (this page) |
| `/health` | GET | Deploy health / secret-presence booleans (no tool data) |

## Error Handling

Errors return a JSON response with an `error` field:

```json
{
  "error": "Tool name is required"
}
```

An unknown tool name returns a 400:

```json
{
  "error": "Unknown tool: get_popular_sets"
}
```

Or for tool execution errors:

```json
{
  "error": "Tool execution failed",
  "details": "Error message..."
}
```

## CORS

`/api/tools` restricts cross-origin requests to an allowlist of known origins:

- `https://www.pokemcp.com`
- `https://pokemcp.com`
- `https://docs.pokemcp.com`
- `http://localhost:3000` / `http://127.0.0.1:3000`
- `http://localhost:3001` / `http://127.0.0.1:3001`

Requests with an `Origin` header outside this list receive a `403` with
`{"error": "Origin not allowed"}`. Requests with no `Origin` header at all (direct server-to-server
calls, `curl`, most non-browser HTTP clients) are allowed through — the allowlist only blocks
disallowed *browser* origins.

## Rate Limits

`/api/tools` enforces a limit of **30 requests per minute per IP** (keyed on the
`CF-Connecting-IP` header). Requests over the limit receive a `429`:

```json
{
  "error": "Rate limited. Please try again later."
}
```
