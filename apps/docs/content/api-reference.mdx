# Endpoints

## MCP endpoint

```
https://api.pokemcp.com/mcp
```

The **[VGC Teambuilder connector](/tools)** is served here over MCP Streamable HTTP. It needs no authentication. See the connector page for its tools.

## Retired endpoints

These legacy endpoints return `410 Gone` and will not come back:

- `https://api.pokemcp.com/sse` — the older SSE transport. Use `/mcp` instead.
- `https://api.pokemcp.com/api/tools` — the REST tool endpoint.

Existing shared-team links remain readable.
