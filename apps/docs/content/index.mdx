# VGC Teambuilder

VGC Teambuilder is a connector for AI assistants. Add it to Claude or ChatGPT and your assistant can look up current Pokémon Champions usage statistics, check whether a team is legal, find its shared weaknesses and track how the metagame is moving — while you talk to it in plain language.

It has no accounts, stores nothing about you and only reads data.

## What you can do with it

- See which Pokémon are used most in a regulation and how each is usually built.
- Find a Pokémon's common teammates and the Pokémon that reliably beat it.
- Check a team against a regulation's allowed list, Species Clause and Item Clause.
- Check which moves a Pokémon can learn.
- See how a team's typing holds up defensively.
- Calculate damage and Speed order for a matchup, and check a team against the most-used Pokémon.
- Follow usage over time: one Pokémon's trend, the biggest risers and fallers, and momentum.
