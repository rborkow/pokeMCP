# Tools

VGC Teambuilder is a [Model Context Protocol](https://modelcontextprotocol.io) server at `https://api.pokemcp.com/mcp`. Every tool only reads data; nothing is written, and no account is needed. To add it to an assistant, see [Connect](/getting-started).

Tools that take a `format` use the newest regulation with published usage statistics when it is omitted. Call `list_formats` to see the supported regulations.

## Where the data comes from

- **Pokémon, moves and abilities** come from the open-source Pokémon Showdown data set.
- **Usage statistics and trends** come from the Pokémon Showdown ladder data that Smogon publishes each month. Percentages are shares of teams or sets, not win rates.
- **Allowed Pokémon lists** come from the published regulation for each format.
- **Damage and Speed calculations** use the open-source calculator behind Pokémon Showdown, in its Pokémon Champions mode: level 50 and stat points.

## Limits worth knowing

- Move checks use Pokémon Showdown's learnset data across all generations, not Pokémon Champions' own move lists. A move from an older game can pass, and a move added only in Champions can be reported as not learnable.
- Team validation checks the allowed Pokémon list, Species Clause, Item Clause, move count, learnable moves and abilities. It does not check stat spreads or held-item availability.
- Type analysis considers typing only, not abilities, items or moves.
- Checks-and-counters data records one-on-one outcomes, so in doubles it is a rough signal.
- Usage rankings come from the most recent month loaded for a regulation and do not state the month; the trend tools show dated history.
- Trend tools need history: two months to compare shifts, three to fit momentum.
- Matchup tools do single calculations. They do not play out a battle, so they say nothing about switching, turn order beyond Speed, or how a game would go.
- When a set is not fully given, the matchup tools fill the gaps with that Pokémon's most common spread, ability and item in the regulation's usage statistics, and list what they assumed.
- A move that hits both opponents is calculated at its reduced doubles damage unless you say only one target is left.

## Privacy

The connector takes no personal information and has no accounts. It records operational metrics for each call (the tool name, format, whether it succeeded and how long it took) and does not store the arguments you send or the results it returns. See the [privacy policy](https://www.pokemcp.com/privacy).
