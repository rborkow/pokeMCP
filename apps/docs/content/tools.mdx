# Public tools retired

The public MCP tools were retired as part of the PokeMCP Prep pivot. Requests to `/mcp`, `/sse`, and `/api/tools` return `410 Gone`.

Pokémon lookup, validation, usage data, trend analysis, and strategy retrieval continue to exist as internal product capabilities. They are not a supported public integration surface.

Use **[PokeMCP Prep](https://www.pokemcp.com)** for tournament research and matchup planning.
