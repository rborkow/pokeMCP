# The website (www.pokemcp.com)

Next.js 16 App Router site deployed to Cloudflare Workers through OpenNext. The directory is
still called `teambuilder`, but there is no team builder, no accounts and no AI here. The product
is the VGC Teambuilder MCP connector served by the worker in `src/` (see the root `CLAUDE.md`);
Claude and ChatGPT are the only interfaces. This site is the connector's content and reference
surface:

- **Home and event pages** — Champions tournament results read from D1.
- **Reports and Pokémon pages** — monthly meta reports and per-Pokémon trend pages, prerendered
  from generated content. This is the SEO surface, and its calls to action point at the connector.
- **Privacy policy** — required by the Claude and ChatGPT directories; covers the connector too.

PokeMCP Prep (matchup plans, saved teams, accounts, the coach) and the team builder were retired
in November 2026. Do not reintroduce interactive features here without the owner asking.

## Routes

| Route | What it is |
|-------|------------|
| `/` | Connector introduction, then recent events and the latest top cut. Server-rendered on demand |
| `/events/[slug]` | One event's published teams and placings. Read-only |
| `/reports`, `/reports/[slug]`, `/reports/[slug]/[month]` | Meta reports (MDX in `src/content/reports/`) |
| `/pokemon/[id]/[format]` | Per-Pokémon trend pages (`src/data/mons/`) |
| `/t/[id]` | Legacy shared-team view, read-only, with "Copy as Showdown text". New links can't be created |
| `/privacy`, `/terms` | Privacy policy and terms of use for the site and the connector. Both URLs are required by the directory listings |
| `/support` | How to get help and report a problem. OpenAI's listing requires a support page URL |
| `/retired` | Notice for the retired features (noindex). Lets a visitor download teams and plans still held in their browser |
| `/prep/*`, `/teams`, `/account`, `/builder`, `/build` | Redirect to `/retired` (`next.config.ts`) |
| `/admin` | Connector usage dashboard behind Cloudflare Access: connections, tool calls, which assistant, failures and response times. Reads the worker's `/admin/api/*` through `/api/admin/*` |
| `/api/health` | Liveness only |
| `/mcp`, `/sse`, `/api/mcp`, `/api/tools` | `410` tombstones pointing at `api.pokemcp.com/mcp` |

Report and Pokémon pages are generated by `scripts/generate-reports.ts` at the repo root and
reach `main` through the monthly review PR. Do not hand-edit generated MDX or JSON.

## What the retirement left behind

**The accounts database is gone.** Accounts, sessions, synced teams, plans and coach
conversations lived in the D1 database `pokemcp-prep`, which was deleted in November 2026 along
with the Discord and Google sign-in apps. The privacy policy and `/retired` say so.

**Visitors' browsers** still hold their saved workspace: IndexedDB database `pokemcp-prep`, store
`workspace`, key `pokemcp-prep-workspace`, plus `localStorage` key `pokemcp-team`.
`SavedWorkspaceExport` reads those names directly so the download works without the old stores.
If you rename or remove it, people lose the only way to get that data out.

**Bindings and secrets.** `wrangler.toml` binds only `META_DB` (read-only here) and `ANALYTICS`.
The site needs no secrets. Do not add an account, auth or AI binding back without the owner
asking.

## Things that will bite you

- **The root `.gitignore` ignores `build/` everywhere.** A route at `src/app/build/` was silently
  never committed, so `/build` returned 404 in production for four months while the header,
  sitemap and reports linked to it. A negation now covers `src/app/**/build/`; still check
  `git status` after adding a directory whose name appears in that file (`lib`, `dist`, `env`, …).
- **`mdx-components.tsx` is loaded by Next by convention.** Nothing imports it, so an
  unused-file scan will flag it. Keep it — the reports are MDX.
- **Don't hard-code a regulation.** The home page once filtered events to one regulation id and
  froze when the next regulation started. Events carry their own `regulationLabel`.
- **The connector is not in the Claude or ChatGPT directories yet.** Copy says "add it as a
  custom connector" with the address. Change that only when a listing is live.
- **Every environment binds production data.** See the root `CLAUDE.md`.

## Conventions

- **File naming**: `PascalCase.tsx` for components, `camelCase.ts` for utilities
- **Imports**: always the `@/` alias; `import type` for type-only imports
- **Client components**: add `"use client"` only where there is interaction
- **Classnames**: `cn()` from `@/lib/utils`
- **Icons**: `lucide-react` only
- **Exports**: named exports; default exports only in `page.tsx`
- **Styling**: Tailwind 4. Pages use the `prep-*` classes in `globals.css` (`prep-shell`,
  `prep-button-primary`, `prep-text-link`); the prefix is historical
- **Formatting**: Biome. Some existing files are not Biome-formatted — format only the files you
  change, or a small edit becomes hundreds of lines of churn
- **Affiliation**: every page that introduces the project carries the unofficial-fan-project
  line (`SiteFooter`)

## Testing

```bash
bun run test:run   # Vitest + React Testing Library + jsdom
bun run ci         # lint, tests, OpenNext bundle, generated-types check, tsc — what CI runs
```

After removing or moving files, serve the build and request the kept pages, a monthly report
above all: it is the route most likely to break without failing a test. Start the server on a
fresh port and stop it by port (`lsof -ti:<port> | xargs kill`) — `next start` renames its
process, so a leftover server will happily keep serving the previous build.
