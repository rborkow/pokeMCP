# ChatGPT plugin package

The package uploaded to OpenAI's plugin portal (platform.openai.com/plugins) to list VGC
Teambuilder in ChatGPT. It wraps the connector at `https://api.pokemcp.com/mcp`; it contains no
code and no skills.

- `plugin.json` — listing text, the four public URLs, starter prompts, and the review test cases
  (five positive, three negative). The portal treats these as read-only: to change them, edit this
  file and upload a new ZIP.
- `mcp.json` — the one remote MCP server.
- `assets/` — icons, generated by `bun run generate-connector-icon`.

Build the ZIP with `bun run package-plugin` (written to `dist/vgc-teambuilder-plugin.zip`).

`src/__tests__/plugin-package.test.ts` checks the manifest against OpenAI's submission limits and
against the connector's real tool names, so a renamed tool fails the build here rather than in
review.

Two things are deliberately not in the manifest and are entered in the portal:

- the demo recording URL, which needs a video;
- reviewer credentials, which do not apply (the connector needs no account).

After connecting the server in the portal, set the domain-verification token it shows:

    bunx wrangler secret put OPENAI_APPS_CHALLENGE --env production

The worker serves it at `https://api.pokemcp.com/.well-known/openai-apps-challenge`.
